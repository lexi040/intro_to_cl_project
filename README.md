# intro_to_cl_project

Course project for *Introduction to Computational Linguistics and Natural Language Processing*: **Sampling the lexicon**.

## About the project

The main topic of this project is how words are distributed in a text: a few words are very frequent, while most words appear only once or twice. We study two classic laws that describe this, **Zipf's law** and **Heaps' law**.

The aim is to see how much these laws depend on the language and on how we define a word, and whether words appear evenly in a text or in bursts.

The project is divided into two parts:

- **Part A: Zipf's law across languages and tokenizers.** We use the multilingual Bible corpus (New Testament only) in English, French, German and Finnish, plus Turkish as an optional extension. We split the text into tokens, estimate the Zipf exponent α, and compare the results with random texts that are not real language.

- **Part B: Heaps' law, word bursts and word embeddings.** We use the Brown corpus and look at how fast new words appear while reading the corpus in different orders, and find which words come in bursts.
